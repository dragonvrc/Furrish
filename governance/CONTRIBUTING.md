# Contributing to Furrish (EN)

We use **RFCs** for significant changes.

Dictionary edits:
1. Fork the repo.
2. Edit `/dictionary/core_100.csv` (keep schema).
3. Open a Pull Request with a short rationale.

RFC (grammar / big changes):
- Copy `/governance/RFC_TEMPLATE.md` to `/governance/rfcs/RFC-YYYY-NAME.md`.
- Fill sections; add examples.
- Open PR; 7-day discussion; simple majority vote.
